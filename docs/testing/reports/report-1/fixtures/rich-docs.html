Using the Fixture API #

This page exists to test whether the extension can convert a typical documentation layout into clean Markdown without copying the site chrome around it.

On this page
  1. Install
  2. Configure
  3. Review output

Install

Start by running npm install fixture-sdk in your project. Read the full installation guide before shipping to production.

The fixture API is intentionally noisy so the exporter has to separate content from chrome.

Configure

The exporter should preserve nested lists like this one:

  • Add a token
    • Use a development token for local work.
    • Rotate the token before sharing the environment.
  • Enable logging
  • Run a dry run

The code block below should become a fenced block with a language.

import { createFixtureClient } from "fixture-sdk";

const client = createFixtureClient({
  token: process.env.FIXTURE_TOKEN
});

await client.pages.copyAsMarkdown("/guide/getting-started");

Review output

Tables and images should survive conversion where possible.

Setting Default Description
includeTitleHeading true Add a top-level heading when needed.
preserveTables true Keep HTML tables as Markdown pipe tables.
